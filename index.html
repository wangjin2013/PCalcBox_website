Getting Started

Set up your passwords

Open Settings → Set Up Password and choose two passwords:

  • The real password opens your real private content.
  • The fake password opens decoy content, so the app's real purpose stays hidden.

Enter or leave privacy mode

Go to Settings → Privacy Mode → Enter Privacy Mode. A working calculator appears:

  • Type your real password and press = to open your real private content.
  • Type your fake password and press = to open the decoy content.
  • Any other input is simply calculated — the app never says "wrong password".
  • If your password contains letters, tap ABC to use the system keyboard; the return key works the same as =.

To leave privacy mode, tap the same row again (it reads Exit Privacy Mode).

Change your passwords

Use Settings → Change Password. You must enter your current password first.

Share files with a computer over Wi-Fi

Go to Settings → File Sharing and turn on HTTP Server. The screen shows an address such as http://192.168.1.23:8080/. Open it in a browser on a computer connected to the same Wi-Fi network: the username can be anything, and the password is your real privacy password. You can then browse the normal, decoy and real folders, download files, and upload new ones.

Add files

In the Photos, Videos or Audio tab, tap + and choose what to import. The Documents tab has no import button — documents arrive through the File Sharing server described above. Use Select to delete items or move them between the real and decoy areas.

Frequently Asked Questions

I forgot my password — can it be recovered?

Passwords themselves cannot be read back out — not even by us. But there is a way out if you have forgotten your real password, so that a vault you can no longer open does not stay locked forever:

Open Settings → Enter Privacy Mode, type 00000000 (eight zeros) as the password and press =. You will be asked to confirm, and then to authenticate as the device owner (Face ID, Touch ID or your device passcode). Once that succeeds:

  • everything in the Hidden area is erased — this cannot be undone;
  • both passwords are cleared, so the app returns to its initial state and you can set up new ones;
  • the Normal and Fake areas are left untouched.

The same code works on the launch screen if you set an entry key. Requiring device-owner authentication is what keeps this from being a way for someone else to destroy your content: knowing the code is not enough.

Note that deleting and reinstalling the app does not clear your passwords either: iOS keeps Keychain items when an app is removed, so the old passwords would still be asked for. Please keep them somewhere safe.

Where are my files stored? Are they uploaded anywhere?

Entirely on your device, inside the app's private storage, and excluded from iCloud and computer backups. Nothing is uploaded to any server of ours. See the Privacy Policy for details.

Why do I see ads, and can I turn off personalised ads?

The app is supported by banner ads from Google AdMob. You can turn off personalised ads in iOS Settings → Privacy & Security → Tracking. Ads will still appear, but they will not be personalised.

What happens if I delete the app?

The files you added are removed from your device, and the built-in HTTP server stops. Your passwords and entry key stay in the iOS Keychain — iOS does not clear them when an app is deleted — so set them up again or change them from inside the app if you reinstall it.
